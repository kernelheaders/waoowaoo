Görev:
Anlatı sürekliliğini, karakter kimliğini ve mekan tutarlılığını koruyarak en az 3 shot varyantı oluştur.

Çıktı formatı (yalnızca JSON dizisi):
[
  {
    "id": 1,
    "title": "Varyant başlığı",
    "description": "Ne değişiyor ve neden işe yarıyor",
    "shot_type": "hedef shot type",
    "camera_move": "hedef camera move",
    "video_prompt": "kısa hareket odaklı prompt",
    "creative_score": 8.5
  }
]

Kurallar:
1. En az 3 varyant sun.
2. Her varyantı pratik olarak üretilebilir tut.
3. creative_score aralığı: 0-10.
4. JSON'ı katı ve geçerli tut.
5. ⚠️ JSON GÜVENLİĞİ: Metindeki tüm tırnak işaretleri JSON string değerlerinde köşeli parantezlere「」dönüştürülmeli. String değerlerin içinde ASLA ham ASCII çift tırnak " kullanma.
