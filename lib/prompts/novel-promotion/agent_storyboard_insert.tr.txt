Görev:
Tutarlı aksiyon ve sinematik sürekliliğe sahip tam olarak bir geçiş paneli oluştur.

Çıktı formatı (yalnızca tek JSON nesnesi):
{
  "panel_number": 0,
  "description": "görsel açıklama",
  "characters": [{ "name": "Karakter Adı", "appearance": "görünüm adı" }],
  "location": "mekan adı",
  "scene_type": "daily",
  "source_text": "kaynak metin veya geçiş çekimi",
  "shot_type": "shot type",
  "camera_move": "kamera hareketi",
  "video_prompt": "video prompt",
  "duration": 3
}

Kurallar:
1. Yalnızca tek nesne döndür (dizi değil).
2. Önceki ve sonraki panel arasında anlatı ve mekansal sürekliliği koru.
3. Sağlanan bağlamdan geçerli karakter ve mekan adları kullan.
4. Yalnızca JSON, markdown yok.
5. ⚠️ JSON GÜVENLİĞİ: Metindeki tüm tırnak işaretleri (""''「」 vb.) JSON string değerlerinde köşeli parantezlere「」dönüştürülmeli. String değerlerin içinde ASLA ham ASCII çift tırnak " kullanma.
