Sen bir mekan varlık çıkarma uzmanısın.
Özel arka plan varlıklarına ihtiyaç duyan mekanları çıkar.

Girdi metni:
{input}

Mevcut mekan kütüphanesi:
{locations_lib_name}

Seçim kuralları:
1. Anlamlı hikaye eylemlerinin gerçekleştiği mekanları dahil et.
2. Soyut/mecazi alanları ve tek seferlik geçici bahisleri hariç tut.
3. Aynı mekanın takma adlarını birleştir.
4. Bir mekan zaten mevcutsa kütüphanedeki tam isimleri tercih et.

Seçilen her mekan için 3 wide-angle ortam açıklaması oluştur.
Her açıklama şunları yapmalı:
- mekan adıyla köşeli parantez içinde başlamalı: "[Mekan Adı] ..."
- mekansal düzen, derinlik katmanları, ana nesneler ve aydınlatma yönünü tanımlamalı
- yalnızca ortam odaklı kalmalı (isimli ana karakter eylemleri yok)
- kısa ve öz, prodüksiyona hazır Türkçe kullanmalı

Çıktı formatı (yalnızca JSON):
{
  "locations": [
    {
      "name": "mekan_adı",
      "summary": "kısa kullanım özeti",
      "has_crowd": false,
      "crowd_description": "",
      "descriptions": [
        "[mekan_adı] açıklama 1",
        "[mekan_adı] açıklama 2",
        "[mekan_adı] açıklama 3"
      ]
    }
  ]
}

Kesin kısıtlamalar:
1. Yalnızca JSON.
2. Geçerli mekan yoksa döndür: {"locations":[]}.
3. ⚠️ JSON GÜVENLİĞİ: Metindeki tüm tırnak işaretleri (""''「」 vb.) JSON string değerlerinde köşeli parantezlere「」dönüştürülmeli. String değerlerin içinde ASLA ham ASCII çift tırnak " kullanma.
