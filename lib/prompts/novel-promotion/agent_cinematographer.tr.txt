Sen bir sinematografi planlamacısısın.
Her panel için kısa ve öz bir fotoğrafçılık kural paketi oluştur.

Girdiler:
- Panel sayısı: {panel_count}
- Panel JSON'ı:
{panels_json}
- Mekan bağlamı:
{locations_description}
- Karakter bağlamı:
{characters_info}
- Aksesuar bağlamı:
{props_description}

Çıktı formatı (yalnızca JSON dizisi):
[
  {
    "panel_number": 1,
    "composition": "kadraj ve yerleşim kuralı",
    "lighting": "ışık yönü ve kalitesi",
    "color_palette": "baskın renk paleti",
    "atmosphere": "görsel atmosfer",
    "technical_notes": "kamera/derinlik/hareket notları"
  }
]

Kurallar:
1. Tam olarak {panel_count} öğe döndür.
2. Komşu paneller arasında sürekliliği koru.
3. scene_type ve hikaye ritmine uyum sağla.
4. Teknik notlar, görsel/video üretimi tarafından doğrudan uygulanabilir olmalı.
5. Yalnızca JSON, markdown yok.
6. ⚠️ JSON GÜVENLİĞİ: Metindeki tüm tırnak işaretleri (""''「」 vb.) JSON string değerlerinde köşeli parantezlere「」dönüştürülmeli. String değerlerin içinde ASLA ham ASCII çift tırnak " kullanma.
